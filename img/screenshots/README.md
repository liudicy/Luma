# Luma screenshots

Captured from the actual signed Luma 1.7.1 application on macOS 27.0.1,
2026-10-16, with the Simplified Chinese interface.

- `launcher-zh.png`: recording launcher, captured as a single window.
- `recording-settings-zh.png`: recording options, captured as a single window.
- `recording-menu-zh.png`: native menu with a recording paused.

Screenshots are direct macOS window captures, not generated mockups. They do
not include a full desktop, recording preview, account data or output paths.
Regenerate them from the current signed application when changing the UI.

The application icon is generated separately by `Scripts/generate_icon.swift`.
